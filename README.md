# Lao Lottery Engine

ระบบวิเคราะห์หวยลาวพัฒนาที่ **ตรวจสอบย้อนหลังได้**: ล็อกชุดเลขก่อนผลออก ตรวจกับผลจริง และเทียบทุกโมเดลกับการสุ่ม

เป้าหมายไม่ใช่การทำนายให้ถูก แต่คือการวัดอย่างซื่อตรงว่าวิธีวิเคราะห์แต่ละแบบทำได้ดีกว่าการสุ่มหรือไม่
(หวยออกแบบสุ่ม ผลที่คาดไว้คือไม่มีโมเดลใดชนะการสุ่มในระยะยาว)

## ทำงานอย่างไร

```
GitHub Actions (จ.–ศ. 20:47, 21:53, 08:37 น.)
  1. ทดสอบโค้ด
  2. ดึงผลจาก ผลหวย.com, Saihuay, LottoTH  → data/sources/*.json
  3. รวมแหล่ง ติดธงงวดที่ขัดกัน               → public/data/results.json
  4. ตรวจคำทำนายที่ล็อกไว้กับผลจริง            → public/data/live.json
  5. Backtest แบบ walk-forward เทียบการสุ่ม   → public/data/backtest.json
  6. สร้างและล็อกคำทำนายงวดถัดไป              → predictions/YYYY-MM-DD.json
  7. commit + push  →  Vercel deploy หน้าเว็บอัตโนมัติ
```

**การล็อก**: ไฟล์ใน `predictions/` เขียนครั้งเดียว สคริปต์ไม่เขียนทับ และ workflow จะ fail ถ้ามีการแก้ไฟล์ที่ล็อกแล้ว
เวลา commit บน GitHub คือหลักฐานว่าล็อกก่อนผลออก คำทำนายที่ล็อกหลัง 20:15 น. ของวันออกผลจะไม่ถูกนับ

## โมเดล

| | มิติคะแนน | น้ำหนักในชุดสรุป |
|---|---|---|
| R1 Short-term DNA | ระยะสั้น (10 งวด) | 1 |
| R2 Weekday | วันเดียวกัน (20 ครั้ง) | 1 |
| R3 Public tips | แหล่งแนวทาง (`data/tips/`) | 1 เมื่อมีข้อมูล |
| R4 License 7-9-8-5-4 | ส่วนบุคคล | 0 จนกว่า backtest ผ่าน |
| R5 Delta/Modulo | ทดลอง | 0 จนกว่า backtest ผ่าน |
| R6 Rolling 30/50/100 | ระยะยาว | 1 |
| R7 Position + ความสัมพันธ์หลัก | รายตำแหน่ง | 1 |
| R8 Opposite | ใช้กับชุดสรุปเท่านั้น | – |

Backtest ปรับค่า p แบบ Bonferroni เพราะทดสอบหลายสิบรายการพร้อมกัน และมีแถว "สุ่ม" ที่ใช้ seed คงที่ไว้เทียบ

## ติดตั้ง

1. สร้าง repo ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ขึ้นไป
2. **Settings → Actions → General → Workflow permissions** เลือก *Read and write permissions*
3. เข้า [vercel.com/new](https://vercel.com/new) เลือก repo นี้ Framework เลือก *Other* (ไฟล์ `vercel.json` ตั้งค่าไว้แล้ว: ไม่มี build, เสิร์ฟโฟลเดอร์ `public/`)
4. แท็บ **Actions → Daily results & locked prediction → Run workflow** เพื่อทดสอบรอบแรก

## รันในเครื่อง

```bash
npm test              # ทดสอบ
npm run fetch         # ดึงผล (ต้องมีอินเทอร์เน็ต)
npm run build         # รวมข้อมูล + backtest + ล็อกคำทำนาย
npm run serve         # เปิด http://localhost:3000
```

ต้องใช้ Node 20 ขึ้นไป ไม่มี dependency

## ข้อควรรู้

- ตัวดึงผลอ่าน HTML ของแต่ละเว็บ ถ้าเว็บเปลี่ยนหน้าตา workflow จะแจ้งเตือนและข้ามแหล่งนั้น ไม่เขียนข้อมูลผิด
- ถ้าแหล่งใดแก้ผลย้อนหลัง จะถูกบันทึกใน `data/source-changes.json`
- การซื้อหวยต่างประเทศในประเทศไทยผิดกฎหมาย โปรเจกต์นี้มีไว้ศึกษาวิธีวิเคราะห์และการทดสอบทางสถิติ
