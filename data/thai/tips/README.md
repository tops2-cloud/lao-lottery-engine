# เลขแนวทางหวยไทย (R3)

ใส่ไฟล์ `YYYY-MM-DD.json` ของงวดนั้น **ก่อน 14:00 น.** ของวันออก แล้วรัน workflow
ถ้าคำทำนายงวดนั้นล็อกไปแล้ว เลขแนวทางจะไม่ถูกนำไปใช้ย้อนหลัง

```json
{
  "sources": [
    {
      "name": "ชื่อสำนัก/เพจ",
      "url": "https://…",
      "fetched": "2026-10-30T09:00:00+07:00",
      "numbers": { "top3": ["123", "456"], "top2": ["23"], "bottom3": ["123"], "bottom2": ["07", "45"] }
    }
  ]
}
```

แหล่งที่มีรายการเลขเหมือนกันทุกตัวจะนับเป็นแหล่งเดียว (ถือว่าคัดลอกกันมา)
